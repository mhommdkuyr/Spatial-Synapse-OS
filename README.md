# Spatial Synapse OS — Ibb Places Scanner

منصة جمع وتوحيد بيانات الأماكن التجارية في مدينة إب، اليمن، باستخدام OpenStreetMap وGoogle Places API.

## المخرجات
- اسم المحل والتصنيف
- الإحداثيات GPS
- العنوان
- الهاتف
- الموقع الإلكتروني
- وسائل التواصل المنشورة
- ساعات العمل
- المنتجات/الخدمات عندما تكون منشورة في المصدر
- مصادر السجل ومعرفاتها
- تقرير التغطية والتكرار والأخطاء

## استراتيجية التغطية
يستخدم المشروع شبكة جغرافية متداخلة بدل استعلام واحد كبير، ويجمع نتائج OSM وGoogle ثم يزيل التكرارات. كثافة الشبكة قابلة للضبط، ولا يعني مصدر واحد أن قاعدة البيانات شاملة لكل المحلات الموجودة على أرض الواقع.

## إعداد Google
لا تضع المفتاح في GitHub. شغّل:
`export GOOGLE_PLACES_API_KEY="YOUR_KEY"`

ثم:
`python -m pip install -r requirements.txt`
`python scripts/ibb_scan.py --config config/ibb.yml`

## المصادر
OpenStreetMap/Overpass وGoogle Places API. يجب الالتزام بشروط استخدام وترخيص كل مصدر وحدود المعدل والتخزين الخاصة به.
